# Мій телеграм-бот для знайомств

Це проєкт телеграм-бота для пошуку нових знайомств та спілкування.

## Як запустити
1. Клонуйте репозиторій:
   `git clone https://github.com/Maksim2/my-telegram-bot`
2. Встановіть залежності:
   `pip install -r requirements.txt`
3. Запустіть бота:
   `python newfile.py`
